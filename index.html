업종 등록현황 통합조회

본 사이트는 AML 업무 지원을 위해 다음 업종의 등록현황을 통합 조회하는 내부 참고용 도구입니다.
• 환전영업자, 소액해외송금업자, 대부업자, 가상자산사업자, 전자금융업자의 등록현황을 상호명 또는 사업자등록번호로 대조합니다.
• 환전영업자와 전자금융업자는 게시기관의 최신 목록 파일을 자동으로 확인하여 갱신합니다.
• 소액해외송금업자와 가상자산사업자는 현재 등록된 자료를 기준으로 조회하며, 신규 자료 확인 시 갱신합니다.
• 대부업자는 FINES 전체 등록목록을 기준으로 대조하며, 목록 건수의 변동 여부를 주기적으로 확인합니다.
• 등록된 목록 파일과 조회 자료는 브라우저에서 대조되며, 입력한 검색어는 외부 조회 서버로 전송하지 않습니다.
• 검색 결과는 내부 AML 업무 참고용이며, 최종 판단 시 각 기관의 공식 사이트에서 최신 자료를 반드시 재확인하시기 바랍니다.

고객 조회

상호명·사업자등록번호 중 하나만 입력해도 조회됩니다. 사업자등록번호가 일치하면 가장 높은 신뢰도로 판정합니다.
업종별 자료 등록
파일형 자료는 CSV 또는 XLSX를 올리면 헤더를 자동 인식해 대조합니다. DRM이 적용된 파일은 브라우저가 읽을 수 없으므로, Excel에서 열어 CSV로 저장하거나 붙여넣기로 등록(Excel 전체 선택 → 복사 → 붙여넣기)을 사용하십시오. 등록한 자료는 이 브라우저에만 저장되며 자료 전체 삭제로 지울 수 있습니다.

조회 결과

조회 결과는 KYC profile 첨부용 근거자료로 사용하기 위해 조회일시·자료기준일자·출처를 함께 기록합니다. 자료 기준일자가 오래된 경우 갱신 후 재조회하십시오.
